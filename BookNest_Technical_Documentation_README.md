# BookNest — Online Bookstore (MERN Stack)

A student full-stack project using React/Vite, Express/Node.js, MongoDB Atlas, GitHub, GitHub Pages, and Render.

## Live links
- **Frontend:** https://amoz225713-web.github.io/online-book-store/
- **Backend API base:** https://booknest-api-xr87.onrender.com
- **Health check:** https://booknest-api-xr87.onrender.com/api/health
- **Books endpoint:** https://booknest-api-xr87.onrender.com/api/books
- **Repository:** https://github.com/amoz225713-web/online-book-store

## Current features
- React/Vite bookstore frontend.
- Express health endpoint.
- MongoDB Atlas integration through Mongoose.
- List books and search by title, author, or category.
- Retrieve one book by ID.
- Create, update, and delete books through API endpoints.
- GitHub Pages frontend deployment and Render backend hosting.

Authentication, checkout/payment, customer orders, and role-based administration are not confirmed as implemented features.

## Technology stack
- MongoDB Atlas — database.
- Express.js — API routing and middleware.
- React — frontend interface.
- Node.js — server runtime.
- Mongoose — data modelling.
- Vite — frontend development/build.
- GitHub Actions / GitHub Pages — frontend deployment/hosting.

## Run locally

### Backend
```bash
cd server
npm install
```
Create `server/.env` locally (do not commit it):
```env
MONGODB_URI=mongodb+srv://<username>:<password>@<cluster-host>/bookstore?retryWrites=true&w=majority
CLIENT_URL=http://localhost:5173
PORT=5000
```
Use your own Atlas credentials and cluster host. URL-encode special characters in the password. Never share the URI publicly.

Start the backend:
```bash
npm start
```
The server defaults to port 5000 locally and uses `process.env.PORT` when provided by the host. Confirm `server/package.json` has `"start": "node src/server.js"`.

### Frontend
In a second terminal:
```bash
cd client
npm install
npm run dev
```
Open the local URL printed by Vite, usually `http://localhost:5173`. The frontend API URL must point to the backend being tested.

## Environment variables and security
- `MONGODB_URI`: private MongoDB connection string. Select the intended database in the URI path (`bookstore`).
- `CLIENT_URL`: allowed frontend origin. For GitHub Pages use `https://amoz225713-web.github.io` (origin only; no repository path).
- `PORT`: supplied by Render; local fallback is 5000.

Never commit `.env` files or credentials. Add `.env`, `server/.env`, `client/.env`, `node_modules/`, and `dist/` to `.gitignore`. Because a database password was shared during troubleshooting, rotate it in MongoDB Atlas and update Render's environment variable.

## API documentation
Base URL: `https://booknest-api-xr87.onrender.com`

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/health` | Health check JSON |
| GET | `/api/books` | List books as JSON array |
| GET | `/api/books?search=atomic` | Search title, author, category |
| GET | `/api/books/:id` | Retrieve one book; 404 if absent |
| POST | `/api/books` | Create a book; returns 201 |
| PUT | `/api/books/:id` | Update a book |
| DELETE | `/api/books/:id` | Delete a book |

### Example JSON for POST
```json
{
  "title": "Atomic Habits",
  "author": "James Clear",
  "price": 399,
  "description": "A practical guide to building good habits.",
  "image": "https://example.com/book-cover.jpg",
  "category": "Self-help",
  "stock": 15
}
```
Use a REST client such as Postman to test POST, PUT, and DELETE. Avoid destructive tests against data you need.

## Book data model
| Field | Type | Required / default |
|---|---|---|
| `title` | String | Required, trimmed |
| `author` | String | Required, trimmed |
| `price` | Number | Required, minimum 0 |
| `description` | String | Default empty string |
| `image` | String | Default empty string |
| `category` | String | Default `General` |
| `stock` | Number | Default 10, minimum 0 |
| `createdAt`, `updatedAt` | Date | Generated by Mongoose timestamps |

## Deployment overview

### GitHub Pages frontend
1. Push code to the `main` branch.
2. GitHub Actions builds the Vite client.
3. The `client/dist` build output is published to GitHub Pages.
4. Check the Actions tab for a successful run.
5. If `vite.config.js` uses `base: '/online-book-store/'`, keep it consistent with the repository Pages URL.

### Render backend
- Root directory: `server`
- Build command: `npm install`
- Start command: `npm start`
- Configure `MONGODB_URI` and `CLIENT_URL` in Render's Environment page.
- Check deployment logs and test `/api/health` and `/api/books`.

### MongoDB Atlas
The connection string must select the database containing the records. If `/api/books` returns `[]` while Atlas shows documents, verify the database path and collection used by the deployed backend before changing frontend code.
